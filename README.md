# Registro de Finanzas / Finance Tracker

## Descripción / Description
App de finanzas personales en Python. Permite agregar ingresos y gastos, ver el historial de movimientos y calcular el balance actual. Los movimientos se guardan automáticamente en un archivo de texto.

Personal finance app in Python. Allows you to add income and expenses, view the transaction history, and calculate the current balance. Transactions are automatically saved in a text file.

## Funcionalidades / Features
- Agregar ingresos / Add income
- Agregar gastos / Add expenses
- Ver historial de movimientos / View transaction history
- Ver balance actual / View current balance
- Guardado automático en archivo de texto / Automatic save to text file

## Cómo usar / How to use
1. Cloná o descargá el repositorio / Clone or download the repository
2. Ejecutá `finanzas.py` con Python 3 / Run `finanzas.py` with Python 3
3. Elegí una opción del menú / Choose an option from the menu
